Opens the full output of every tool call this session, not the summary shown in the chat. Press again, or Esc, to close.

Every tool run is saved in full even though the chat only shows a trimmed version — this is where the rest lives, including the results of runs you sent to the background with Ctrl+B. With the overlay open, ← and → page between tool calls (oldest to newest), and PgUp/PgDn scroll within the one you're looking at. It shares its slot with the summary overlay (Ctrl+S) — opening one closes the other.

## Examples

    Ctrl+O
    Ctrl+O, then → → to page forward through tool calls
