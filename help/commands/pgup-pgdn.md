Scrolls whichever overlay is currently open — the tool-output browser (Ctrl+O) or the session summary (Ctrl+S) — half a screen per press.

When no overlay is open, the chat pane itself scrolls with these keys instead. Mouse wheel scrolling is intentionally left off so the terminal's own native text selection and copy keep working; PgUp/PgDn is the keyboard-only substitute.
