Prints this list — every command, trick and key ayin has, grouped into sections, plus any slash commands added by installed tools.

It is rendered from one registry shared with the typing-hint panel and the startup tip line, so a command documented here cannot be silently missing from the hint panel or vice versa. Tool-provided commands are listed separately at the bottom, under their own heading, because they come from whatever tools are registered rather than from this fixed list — an installed tool can add a command this file has never heard of.

## Examples

    /help
