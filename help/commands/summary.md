Opens the session summary overlay — the rolling summary ayin keeps of the conversation once it gets long enough to compress. Same key as Ctrl+S.

Useful for checking what the agent thinks the conversation has been about so far, especially before trusting it with a follow-up that depends on earlier context that may have scrolled out of the window. Esc closes the overlay; PgUp/PgDn scroll it while it's open.
