Turns corpus injection on or off — whether reading a file also shows what an earlier `ayin indulge` run already answered about it, and whether the first prompt of a session is looked up automatically. On by default.

This is the master switch for retrieval from the repo corpus; `/embed` and `/embedthis` only have anything to do while this is on. Turn it off to A/B a task honestly: run it once with `/corpus off`, once with it on, and compare — that is the only trustworthy way to tell whether the corpus is actually helping, rather than assuming it is. With it off, an explicit `corpus_search` call still works; only the automatic injection into tool results and first-prompt lookup stop.

## Examples

    /corpus off
    /corpus
