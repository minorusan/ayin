Move or remove an object in a Unity asset — the structural edits prefab_edit deliberately cannot make. op=reparent moves a GameObject under another parent, or to the file root when `to` is omitted; op=delete removes a GameObject with its components and every descendant, or one component when `component` names it. Pass dry_run=true first and read the diff. A delete REFUSES when anything still references what would go, naming the referrers, because Unity drops a dangling reference silently and the loss surfaces in the editor days later. It cannot ADD components: their serialized defaults come from the C# class, and a guessed default produces a file that parses and is wrong.
