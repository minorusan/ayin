Draw the real dependency graph around one or more start files, derived from the source — no model, no guessing, the same answer every time. Give it the file you are standing on while reading a bug and it returns every type it touches, grouped by the ASSEMBLY that owns it: in Unity the .asmdef, with what it may reference and whether it is sealed off from the engine — facts the source itself does not show. Base classes and interfaces are followed to the very end, because a type's supertypes are what it IS; the types its members name are followed `depth` hops, default 3. A type reached at the limit is drawn with no members. Use explore to find the file, this to map out from it.
