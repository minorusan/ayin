Run named Unity test assemblies and report the result per test, with the failing assertions. Name them exactly as unity_tests_which prints them, comma separated — a run is scoped by assembly and running every test in a large project takes an hour. Assemblies whose compiled DLL is current run from it in seconds; anything stale or never compiled needs Unity batch mode, which needs the Editor closed, and the operator is asked before that happens. A decline, or nobody present to ask, means nothing runs and the reply says so. An assembly that fails to load is reported as not run, never counted as passing.
