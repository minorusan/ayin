Start here when you do not know the exact symbol or filename — use grep instead when you know the literal string to match. One call runs a battery of read-only searches in parallel and returns ranked file:line spans quoted verbatim, plus couplings that are not plain text: in Unity the .meta GUID binding a script to a prefab or .anim, in TypeScript the string keys (event names, tool names, prompt ids) joining files with no import between them. It derives identifiers from plain words, so "time bonus" finds GetTimeBonus(). Sub-second and deterministic — no model inside, so it cannot invent anything, and finding nothing is a real answer.
