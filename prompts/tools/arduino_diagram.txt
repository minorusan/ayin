Draw the WIRING for the Arduino project in the current directory: one rectangle for the board with a nested rectangle per pin actually used, one rectangle per real component with a nested rectangle per leg, wires drawn as labeled arrows between exact pins — grounded in the real sketch code and the arduino_db catalog, never a generic or invented circuit. Renders as an editable vector (.puml + .svg, draggable in Inkscape/draw.io) and opens in VS Code. Use for wiring, circuit, or "how does this connect" questions on an Arduino project — never the generic diagram tool, which has no idea what components are actually wired.
