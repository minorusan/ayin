Rename a symbol and every reference to it across C# or TypeScript/JS files in one operation. Prefer this over str_replace or sed for any rename: it matches whole identifiers only (never inside FooBar), leaves strings and comments alone but reports every mention in them, and handles what breaks silently — a Unity MonoBehaviour is renamed with its file (Unity binds a component by file name), [FormerlySerializedAs] is added for a renamed serialized field (its old name is the key every prefab stores the value under), and a TS object shorthand is expanded so a data key does not follow the symbol. Pass dry_run=true first to read the plan.
