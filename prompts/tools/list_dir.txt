List a directory: names, whether each is a directory, size, and how recently it changed. Prefer this over `ls` in bash — it is bounded, sorted with directories first, skips generated caches, and says when it truncated. The mtime column answers "which of these did the last run touch" without a second call. recursive=true adds one level inside each subdirectory; all=true includes dotfiles. Use find_files instead when you already know the name pattern, and read_file for a file's contents.
