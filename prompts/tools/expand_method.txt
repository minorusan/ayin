Return one method body from a file, by name, with the lines it occupies and what it touches. Use after a read of a large file returned its structure instead of its text: the structure names each method and its line range, this returns the code. Takes Class.method when several classes declare the same name; a bare name matching more than one is refused, listing them. The lines it shows count as read, so an edit to them is allowed without reading the file again.
