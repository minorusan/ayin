Set ONE property in a Unity .prefab, .unity or .asset, surgically — the file differs by one line. Point a reference at another asset by FILE NAME (asset=Hero_SkeletonData.asset): the name resolves to its guid and the existing fileID and type are kept, so the reference stays valid. Or set a scalar (value=0.5), including one field of a vector (property=m_Pivot.x). Address the target with object=<hierarchy path> and component=<class name>, exactly as prefab_inspect prints them, or component=#<fileID> when two components share a class. An ambiguous name, and a reference whose class does not match the field, are refused rather than written. Properties only: it adds and removes nothing.
