WHO references this file — the reverse of reading it, and what to ask before changing or deleting anything. Given a path to a Unity asset it returns the prefabs, scenes and assets referencing it, resolved through the .meta guid, which is the only place that link is written and which no search for the class name can find. Given source it returns every file naming the types that file declares, in C#, TypeScript, Dart, Python, Go, Rust, Ruby, Java or C++. A bare 32-character guid works too: it answers which asset that is, and who uses it. The source half is a text search and says so, so a hit is a mention and a comment counts; the Unity half is exact. Read-only.
