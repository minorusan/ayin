Read a file and return its contents with line numbers. Use offset/limit for large files, around= to centre a window on a grep hit, tail= for the end of a log. structure=true returns the file's SHAPE instead of its lines — every type and member with its exact line range, no bodies — which is how you get a class skeleton, the serialized fields of a MonoBehaviour or an API surface without reading the whole file; expand_method then returns one body. For image files (png/jpg/jpeg/webp/gif/avif/tiff/bmp) the image is downscaled and attached to the next LLM call for vision processing instead of returning bytes. PDFs are not supported — rasterize to PNG first.
