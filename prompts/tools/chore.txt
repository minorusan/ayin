Find members added in recent commits that nothing uses — dead code while it is still fresh. Takes the files the last N commits touched (10 by default), extracts the methods, properties and fields those commits added, drops any whose declaration is no longer in HEAD (added-then-removed is history, not dead code), then searches the tracked tree for each survivor. Every item carries the commit that introduced it, so it is a decision rather than archaeology. Code and assets are both searched: a Unity field is named from a prefab, a method from a clip. Reflection-invoked members ([Test], [MenuItem], [SerializeField], DI) are excluded and counted — they have no callers by design. Read-only.
