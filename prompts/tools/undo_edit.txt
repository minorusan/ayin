Revert your most recent edit, restoring the exact bytes it replaced. Pass a path to undo the last edit to one file; call it again to walk further back, newest first. It refuses when something other than your own recorded edit has written the file since, and says so with both hashes, rather than discarding that change silently — read the file, then pass force=true if you still want the old bytes. Use this rather than git checkout to undo your own work: it reverts one edit, where a checkout throws away everything uncommitted in the file.
